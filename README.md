# Cynea AI - Professional Corporate Website

A production-ready, fully accessible, and GDPR-compliant website for Cynea AI - serving SMEs, Corporates, and Government entities across the UK and emerging markets.

## 🌟 Features

### Core Functionality
- ✅ **Responsive Design** - Mobile-first approach, works on all devices
- ✅ **Modern Tech Stack** - React 18, TypeScript, Vite, Tailwind CSS v4
- ✅ **Component Library** - Radix UI for accessible components
- ✅ **Routing** - React Router for seamless navigation
- ✅ **SEO Optimized** - Meta tags, structured data, semantic HTML

### UK GDPR Compliance
- ✅ **Cookie Consent Banner** - UK-compliant with granular preferences
- ✅ **Privacy Policy** - Comprehensive UK GDPR-compliant policy
- ✅ **Terms of Service** - Legal terms and conditions
- ✅ **Accessibility Statement** - WCAG 2.1 AA commitment
- ✅ **GDPR-Compliant Forms** - Required consent checkboxes, data transparency

### Accessibility (WCAG 2.1 Level AA)
- ✅ **Keyboard Navigation** - Full keyboard support
- ✅ **Screen Reader Compatible** - ARIA labels and semantic HTML
- ✅ **Color Contrast** - All text meets AA standards (4.5:1 minimum)
- ✅ **Focus Indicators** - Visible focus states for all interactive elements
- ✅ **Skip Links** - "Skip to main content" for faster navigation
- ✅ **Reduced Motion** - Respects user preferences for animations

### Design System
- ✅ **Professional Typography** - Nunito Sans with clear hierarchy
- ✅ **Semantic Colors** - Success, error, warning, info states
- ✅ **Interactive States** - Hover, focus, active, disabled, loading
- ✅ **Consistent Spacing** - Systematic spacing scale
- ✅ **Shadow System** - Elevation for depth and hierarchy

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ ([Download](https://nodejs.org/))
- npm or pnpm

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/shimoli007/figma-website-structure-.git
   cd figma-website-structure-
   cd "Website Copy and Structure (1)"
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

### Build for Production

```bash
npm run build
npm run preview  # Preview production build locally
```

## 🎨 Design System

### Typography
- **Primary Font**: Nunito Sans (400, 500, 600, 700, 800)
- **Heading Sizes**: 48px (H1) → 18px (H6)
- **Body Text**: 16px with 1.6 line-height

### Color Palette

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Primary** | #072048 | Headers, navigation, primary CTAs |
| **Accent** | #eca52e | Secondary CTAs, highlights |
| **Success** | #10b981 | Success messages, confirmations |
| **Error** | #ef4444 | Error states, destructive actions |
| **Warning** | #f59e0b | Warnings, cautionary messages |
| **Info** | #3b82f6 | Informational content |

All colors meet WCAG AA contrast requirements.
